# FloodSpy Weather

A cyberpunk-themed weather monitoring application with advanced visualization features built using Next.js.

## Features

- Interactive 3D globe visualization using Three.js
- Real-time weather monitoring with cyberpunk UI
- Weather cards with detailed information
- News feed with weather-related articles
- Timeline viewer for historical data
- Live feed of weather updates
- Particle rain effects for visual enhancement

## Technologies

- Next.js 15
- React 19
- Three.js with React Three Fiber
- Tailwind CSS
- Radix UI components
- GSAP for animations
